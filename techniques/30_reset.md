# Wiederherstellen

| Command                      |                                                                                             |                                                                                                                                                                                   |
|------------------------------|---------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `git reflog`                 | Die Historie des aktuellen Git Directories                                                  |                                                                                                                                                                                   |
| `git reset --soft <Commit>`  | Setze `<aktueller Branch>` auf `<Commit>` und ändere Index sowie Working Tree nicht.        | Alle Änderungen die bereits committet waren, landen im Index. Alles was bereits gestaged war, bleibt im Index. Noch nicht committete Änderungen im Working Tree bleiben erhalten. |
| `git reset --mixed <Commit>` | Setze `<aktueller Branch>` auf `<Commit>`, resette den Index aber behalte den Working Tree. | Alle Änderungen die bereits committet, gestaged, oder im Working Directory waren, landen oder bleiben im Working Directory.                                                       |
| `git reset --hard <Commit>`  | Setze `<aktueller Branch>` auf `<Commit>` und resette Index sowie Working Tree.             | Verwerfe alle Änderungen (bereits committet, gestaged, im Index oder Working Tree) bis `<Commit>`.                                                                                |
